# 🧹 Innovate7 — Cleaning Service Landing Page

> A professional cleaning service website built with **HTML**, **CSS**, and **Bootstrap**.

🌐 **Live Demo:** [innovate7.vercel.app](https://innovate7.vercel.app/)

---

## 📌 About The Project

**Innovate7** is a fully responsive cleaning service company landing page. The site represents a certified commercial cleaning company — **Queak** — offering house cleaning, office cleaning, furniture cleaning, and more. Built with pure HTML, CSS, and Bootstrap for fast loading and easy customization.

## 🚀 Getting Started

No build tools or installations required! This is a pure static site.

### Option 1 — Open directly

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/innovate7.git
   cd innovate7
   ```

2. **Open in browser**

   Simply open `index.html` in any browser — done! ✅

### Option 2 — Use Live Server (Recommended for development)

1. Install the **Live Server** extension in VS Code
2. Right-click on `index.html`
3. Select **"Open with Live Server"**

---

## 🌍 Deployment

This project is deployed on **Vercel** as a static site. To deploy your own version:

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com) and import your repository
3. Vercel auto-detects it as a static site
4. Click **Deploy** — done! ✅
